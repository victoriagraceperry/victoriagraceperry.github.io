# Victoria Perry — Engineering Portfolio

Personal portfolio site for Victoria Perry.

## GitHub Pages

This repository is intended to publish at:

https://victoriagraceperry.github.io

GitHub Pages can publish a user site from a repository named `victoriagraceperry.github.io`.

## Structure

- `index.html` — main site
- `style.css` — styling
- `assets/` — resume and future images
- `projects/` — future project pages

## To update

Edit `index.html` and `style.css`, then commit the changes. GitHub Pages will rebuild the site automatically when configured to deploy from the main branch.
